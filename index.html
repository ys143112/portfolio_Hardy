AI 작업 지침과 실행 검증

Unity 작업 순서를 제안하고, Claude Code와 Codex가 따를 지침을 작성했습니다. 팀원이 작업을 시작하거나 중단된 작업을 이어갈 때 참고할 안내도 저장소에 남겼습니다.

실행해서 찾은 문제

빌드는 통과했지만 한 기능에서 값을 불러오지 못했습니다. 기능별 로그가 남도록 명세를 바꾸고 다시 실행해 값 연결이 빠진 곳을 찾았습니다.

기획 결과 확인과 승인
“승인 전에는 Unity 구현이 시작되지 않습니다.”

기획 결과를 확인한 뒤 승인해야 다음 작업을 진행할 수 있습니다.

작업 상태 조회

실행 시 받은 작업 ID로 현재 단계를 조회합니다.

python -m phase_runner status <run-id>
작업 재개

승인을 마치고 다음 단계를 진행할 때 쓰는 명령입니다.

python -m phase_runner resume <run-id>
